# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | ✅                |
| 1.0.x   | ✅                |
| 0.9.x   | ❌                |
| < 0.9   | ❌                |

## Reporting a Vulnerability

We take the security of AgriGuru Global seriously. If you believe you've found a security vulnerability, please follow these steps:

1. **Do not disclose the vulnerability publicly** until it has been addressed by our team.
2. Email us at komalsrinivasan.l@gmail.com with details about the vulnerability.
3. Include the following information in your report:
   - Type of vulnerability
   - Path or location of the affected source code
   - Step-by-step instructions to reproduce the issue
   - Potential impact of the vulnerability
   - Any suggested fixes (if available)

## What to Expect

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will send you regular updates about our progress.
- Once the vulnerability is confirmed, we will work on a fix.
- If the vulnerability is accepted, it will be fixed as soon as possible, depending on complexity.
- If the vulnerability is declined (e.g., if it's not reproducible or out of scope), we will provide an explanation.
- Once the fix is ready, we will release a security update.
- After the update is released, we will publicly acknowledge your responsible disclosure, unless you prefer to remain anonymous.

## Security Measures

AgriGuru Global employs several security measures to protect user data:

- End-to-end encryption for sensitive data
- Regular security audits and code reviews
- Secure authentication mechanisms
- Rate limiting to prevent brute force attacks
- Input validation and output encoding to prevent injection attacks
- Regular dependency updates to address known vulnerabilities

Thank you for helping keep AgriGuru Global and our users safe!
